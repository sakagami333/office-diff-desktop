Office差分ツール（デスクトップ版）
==================================

2つの Word（.docx）または PowerPoint（.pptx）ファイルを比べて、
変更点を、ブラウザで見られる .html ファイルと、テキストの .diff ファイルに
書き出します。
Office のインストールは不要です。Windows 10 / 11 標準の機能だけで動きます。


■ 準備（最初の1回だけ）
  1. ダウンロードした zip ファイルを右クリック →「プロパティ」→ 下の方の
     「許可する」にチェック → OK
     （これをしないと、実行時に警告が出ることがあります）
  2. zip を展開し、OfficeDiff フォルダごと好きな場所に置きます（デスクトップなど）
       OfficeDiff.bat
       OfficeDiff_入れ替え.bat
       OfficeDiff.ps1        ← 本体。.bat と同じフォルダに置いたままにしてください
       README.md / images    ← 画像付きの説明書（VS Code などで表示）
       使い方.txt            ← この説明書
       output               ← 比較結果の保存先（初回の実行で自動的に作られます）


■ 使い方（3通り。どれでも同じ結果になります）
  A. 2つのファイルが同じフォルダにあるとき
     Ctrl キーを押しながら2つを選び、まとめて OfficeDiff.bat にドラッグ＆ドロップ

  B. 別のフォルダにあるとき（同じ名前のファイル同士など）
     1つ目のファイルだけを OfficeDiff.bat にドラッグ＆ドロップ
     → ファイル選択画面が開くので、比べるもう1つのファイルを選んで「開く」

  C. OfficeDiff.bat をダブルクリック
     → ファイル選択画面が2回開くので、1つずつ選ぶ

  黒い画面に結果が出て、差分の HTML がブラウザ（Edge など）で開きます。
  何かキーを押すと黒い画面が閉じます。

  ・更新日時が「古い方」を変更前、「新しい方」を変更後として比べます
  ・前後が逆になったときは、OfficeDiff_入れ替え.bat にドロップし直してください
  ・結果は OfficeDiff フォルダの中の output フォルダに、次の2つが保存されます
    （output フォルダが無ければ自動で作ります）
      <ファイル名>_差分_<日付-時刻>.html  … ブラウザ表示用
      <ファイル名>_差分_<日付-時刻>.diff  … テキスト版（エディタ用）
    .html はメールやチャットで渡せば、相手もブラウザだけで見られます


■ 結果の見方
  HTML（ブラウザ）では、緑＝追加、赤＝削除 で色分けされ、行の中で変わった
  文字だけが濃い色になります。左の一覧から、変更のあったスライド
  （Word は見出しごとの変更箇所）へ移動できます。

  .diff ファイル（テキスト）では:
  行頭が「-」… 変更前にあって、変更後で消えた行（削除）
  行頭が「+」… 変更後に増えた行（追加）
  行頭が空白 … 変わっていない行（前後の文脈）

  PowerPoint はスライド単位で比べます。
    ## スライド 3          … 3枚目の中身が変わった
    ## スライド 5 → 4      … 5枚目だったスライドが4枚目になり、中身も変わった
    -## スライド 4（削除）  … 4枚目のスライドが削除された
    +## スライド 2（追加）  … 2枚目にスライドが追加された
  内容が同じで番号だけ変わったスライドは表示しません。

  .diff ファイルは VS Code や Notepad++ で開くと、追加行が緑・削除行が赤で
  色分けされます。


■ 対象外
  ・文字の色・フォント・配置など、書式だけの変更
  ・画像そのものの変更（画像の名前は [画像: 図 3] のように表示されます）
  ・旧形式の .doc / .ppt（Office で .docx / .pptx に保存し直せば使えます）
  ・パスワード付きのファイル
  ・Excel（.xlsx）


■ うまく動かないとき
  ・黒い画面が一瞬で消える / 何も起きない
      → 3つのファイルが同じフォルダにあるか確認してください
  ・「スクリプトの実行が無効」「デジタル署名されていません」と出る
      → 会社のPCの設定で PowerShell が制限されています。情報システム部門に相談してください
  ・ファイル選択画面が見当たらない
      → 黒い画面やほかのウィンドウの後ろに隠れていることがあります。タスクバーを確認してください
